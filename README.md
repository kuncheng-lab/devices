# devices

设备通信协议客户端集合，用于本团队多个桌面应用：

- `atlas_pf6000`：Atlas Copco PF6000 拧紧工具（OpenProtocol）
- `melsec_plc_fx2n` / `melsec_plc_fx3u` / `melsec_plc_fx5u`：三菱 PLC 通信
- `siemens_s7`：西门子 S7 通信

## 说明

本项目由人与 AI 共同完成，只适合我们团队内部项目使用，接口与行为可能随时调整，请勿用于生产依赖。
